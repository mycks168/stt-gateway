# コンセプト

## 目的

音声ファイルを HTTP で受け取り、文字起こし結果を JSON で返すゲートウェイ。
クライアント（音声入力アプリや AI エージェント）は、音声認識エンジンの違いを意識せずに
同じ API で文字起こしを使える。

## 方針

- **エンジンを差し替えられる**：faster-whisper（多言語）と Haas-ja（日本語専用）を設定で切り替える。
  API の入出力は、どちらのエンジンでも同じ形にする。
- **日本語の精度と応答速度を重視する**：主な用途は日本語の音声指示。日本語の評価で
  Whisper を上回るエンジン（Haas-ja）を選べるようにする。
- **重い依存は必要な人だけが入れる**：Haas-ja は NeMo と torch を必要とし、環境が数GB 増える。
  Whisper だけを使う環境には入れない。
- **閉じたネットワークでも最低限の認証を持つ**：Bearer トークンで保護する。
